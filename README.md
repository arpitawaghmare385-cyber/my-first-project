# Travelease – Tour and Travel Website

## About the Project

Travelease is a web-based Tour and Travel Management System designed to help users explore travel destinations, view tour packages, and book their trips online.

The project provides a user-friendly interface for travelers and an admin panel to manage bookings and packages.

## Features

* User-friendly Homepage
* Explore Travel Destinations
* View Tour Packages
* Package Details and Itinerary
* Online Booking System
* User Login
* Admin Login
* Booking Management
* Payment Status Management

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL
* XAMPP

## Software Requirements

* Visual Studio Code
* XAMPP Server
* Web Browser

## How to Run the Project

1. Install XAMPP on your computer.
2. Copy the project folder into `htdocs`.
3. Start Apache and MySQL from XAMPP.
4. Create a database named `travelease` in phpMyAdmin.
5. Configure the database connection in `db.php`.
6. Open your browser.
7. Visit `http://localhost/travelease/`.
